# Golden evaluation data

Private production evaluation records should stay outside the public repo. The
synthetic checked-in corpus is under `datasets/demo/`.

For a real public RAG benchmark, use `make hf` (requires network and optional
`datasets` dependency) to download 50 rows of Hugging Face
[`galileo-ai/ragbench`](https://huggingface.co/datasets/galileo-ai/ragbench),
`covidqa` / `test` split. This dataset contains retrieved passages, questions,
model responses, and annotation fields; it is **not** a fully labeled tool-trajectory
or document-ACL benchmark. The downloader preserves original fields in separate
records. To score end-to-end RAG, **ingest the supplied documents**, re-answer
the questions, and label relevant evidence. Do not score the dataset's existing
`response` as though it were generated by this repository.
